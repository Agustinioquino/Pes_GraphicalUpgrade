# PES21FX PesEditorRebuilt - downloads

Shared builds of the graphics mod (27-31/10/2026). Click a file and use "Download raw" / "View raw".

| File | What it is |
|---|---|
| `pes21fx_Peseditorrebuilt.zip` | Main package: d3d11.dll, PES21FX folder (ini, shaders, textures, menus in Spanish / English / Portuguese), Sider modules. Read README.txt / LEEME.txt / LEIAME.txt inside. |
| `pes21fx_Peseditorrebuilt_manos_originales.zip` | Same package with every hand / arm deformation card switched off, for use with the body pack that keeps the original game hands. |
| `SinCamiseta.zip` | Standalone Sider module to hide the shirt, sleeves and shorts in the Edit menu. |

The body pack (`pes21fx_Peseditorrebuilt_cuerpo*.zip`, 431 MB: "PES21FX Body Model" + TorsoBody livecpk folders) is too big for this folder and is shared separately.

Checksums: `SHA256.txt`.
